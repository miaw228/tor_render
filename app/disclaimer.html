Purpose

This project was built purely for research and learning purposes — to understand Tor hidden services works on renders infra inside a docker container or not and with no persistent disk and no official Tor support. It is a technical experiment, not a product.

This project is not intended for, and must not be used for, any illegal activity. The author takes no responsibility for any misuse of this code or the techniques described in this repository.

No warranty

This is a demo, not production infrastructure. It comes with no guarantees of uptime, security, or fitness for any particular purpose. Use it as a reference, not a dependency.

If you fork this

Generate your own hidden service keys — don't reuse the ones in this repository. The private key is what gives a .onion address its identity; if it ever leaks, that address can be impersonated indefinitely.
